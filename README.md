# Course_project_on_algorithmization

# Контракт v1

Договорённость о стыке частей проекта WeedVision. Менять только по согласию обоих участников, с коммитом «Контракт vN».

## 1. Координаты
- Клетка задаётся кортежем `(row, col)`.
- Нумерация с нуля: `(0, 0)` это левый верхний угол, `row` растёт вниз, `col` растёт вправо.
- Движение только на 4 соседние клетки (вверх, вниз, влево, вправо), диагоналей нет.
- Шаг на соседнюю клетку стоит 1.

## 2. Формат поля
- `weed`: `numpy.ndarray`, форма `(H, W)`, тип `float`, значения от 0 до 1 (уровень засорения).
- `obstacles`: `numpy.ndarray`, форма `(H, W)`, тип `bool`, `True` означает, что клетка непроходима.
- Объект `Field` из `simulator/field.py` хранит `weed`, `obstacles`, `H`, `W`.
- Поле по умолчанию 30×30, но код не должен зависеть от размера.

## 3. Параметры робота (файл `config.py`)
- `START = (0, 0)`: стартовая клетка.
- `TANK_CAPACITY`: сколько клеток можно обработать на одном баке.
- `WEED_THRESHOLD = 0.5`: клетка считается целью, если засорение не ниже порога.
- `SEED = 42`: для воспроизводимости экспериментов.

## 4. Сигнатуры функций

| Функция | Файл | Владелец | Вход | Выход |
|---|---|---|---|---|
| `predict_weed_map(field, history)` | `ml/forecast.py` | B | поле и история засорения | `np.ndarray (H, W)`, значения 0-1 |
| `plan(weed_map, field, config)` | `planning/*.py` | A | карта засорения, поле, параметры | `list[(row, col)]`: какие клетки обработать |
| `route(field, targets, start)` | `routing/*.py` | A | поле, цели, старт | `list[(row, col)]`: полный путь по клеткам |
| `evaluate(field, path, targets)` | `simulator/evaluate.py` | B | поле, путь, цели | `dict` с метриками |

Правила:
- Функции не меняют переданное поле и возвращают новые объекты.
- Путь всегда начинается со `START` и не проходит через препятствия.

## 5. Метрики (ключи словаря из `evaluate`)
- `path_length`: число шагов в пути.
- `sprayed_cells`: сколько клеток обработано.
- `weeds_killed`: сумма засорения в обработанных клетках.
- `weeds_missed`: сумма засорения в необработанных клетках выше порога.
- `efficiency`: `weeds_killed / path_length`.
- `runtime_sec`: время работы алгоритма.

## 6. Формат данных для ML
CSV-файл в `data/`, одна строка на клетку в один момент времени:

`simulator_id, step, row, col, weed_now, neighbors_mean, is_obstacle, weed_next`

`weed_next` это целевая переменная: будет ли клетка засорена (выше порога) на следующем шаге.

## 7. Правила работы
- Контракт меняется только по согласию обоих участников, с коммитом «Контракт vN».
- Пока модуль не готов, используется заглушка. Например, `ml/forecast.py` возвращает текущее поле без изменений.
- Стык проверяет `tests/test_contract.py`: форма и тип выходов, путь без препятствий, наличие всех ключей метрик.
