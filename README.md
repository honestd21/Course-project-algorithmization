# WeedVision: планирование работы робота-опрыскивателя

Курсовая работа по алгоритмизации.

## О чём проект

Автономный робот-опрыскиватель обрабатывает поле с сорняками. Бака хватает
не на всё поле, поэтому нужно решить две задачи:

1. Какие клетки обработать (выбор под ограничение бака).
2. В каком порядке и каким путём их объехать, обходя препятствия.

Робот видит засорение только там, где уже был. Модель машинного обучения
прогнозирует, где сорняки будут, и планирование идёт по прогнозу.

**Цель:** сравнить алгоритмы планирования и маршрута и проверить, насколько
ML-прогноз повышает эффективность обработки поля.

## Соглашения

### Координаты
- Клетка задаётся кортежем `(row, col)`, нумерация с нуля.
- `(0, 0)` это левый верхний угол, `row` растёт вниз, `col` растёт вправо.
- Движение только на 4 соседние клетки, диагоналей нет.
- Шаг на соседнюю клетку стоит 1.

### Поле
- `weed`: `numpy.ndarray` формы `(H, W)`, значения от 0 до 1.
- `obstacles`: `numpy.ndarray` формы `(H, W)`, тип `bool`, `True` значит непроходимо.
- Класс `Field` (`simulator/field.py`) хранит `weed`, `obstacles`, `H`, `W`.
- Поле по умолчанию 30x30, но код не должен зависеть от размера.
- Клетка является целью, если засорение не ниже порога и нет препятствия.

### Робот
- Параметры (старт, бак, порог, расход) задаёт `RobotParams` в `planning/params.py`.
- Для воспроизводимости экспериментов используется `seed`.

### Общие правила
- Функции не меняют переданное поле и возвращают новые объекты.
- Путь начинается со стартовой клетки и не проходит через препятствия.

## Алгоритмы

| Задача | Алгоритмы | Где |
|---|---|---|
| Порядок обхода целей | змейка, ближайший сосед, 2-opt | `routing/` |
| Путь между двумя клетками | BFS, A* | `routing/` |
| Выбор клеток под бак | жадный, динамическое программирование | `planning/` |
| Прогноз засорения | модель из scikit-learn | `ml/` |

## Метрики

Считаются по настоящему полю в `planning/evaluate.py`: охват, длина пути,
число клеток, обработанных зря, время работы.

## Данные для ML

CSV в `data/`, одна строка на клетку в один момент времени:

`field_id, step, row, col, weed_now, neighbors_mean, is_obstacle, weed_next`

`weed_next` это целевая переменная: будет ли клетка засорена на следующем шаге.

## Структура репозитория

- `simulator/`: поле, генерация, соседи клетки
- `routing/`: порядок обхода и поиск пути
- `planning/`: выбор клеток, параметры робота, метрики
- `ml/`: прогноз засорения
- `experiments/`: запуск сравнений
- `results/`: таблицы и графики
- `data/`: данные для ML
- `tests/`: автоматические проверки
- `report/`: текст курсовой
